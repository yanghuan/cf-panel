## 1. 概览

单页原生 JS 应用（无框架），IIFE 封装，功能面覆盖：登录、分组服务器卡片列表（WS 推送驱动）、xterm 终端、文件管理（上传/下载/通配符过滤）、Chart.js 监控图、PAT/审计/用量/告警设置。第三方依赖全部本地化（`public/vendor/`：xterm 290KB、chart.js 205KB、addon-fit 1.8KB），无 CDN/供应链风险。

**总体评价**：UI 精致（暗色渐变 + 毛玻璃 + 呼吸灯 + hover 层叠处理），UX 细节丰富（空闲观看保护、后台标签页断连、终端自愈重连、Esc/焦点可访问性），安全措施系统（CSP + escapeHtml 全覆盖 + token 不进 URL）。发现 **0 Critical / 0 High / 3 Medium / 13 Low**，无安全漏洞。

- 细节处理成熟：tooltip 挂 body 下防 transform 包含块破坏 fixed 定位（`app.js:1310-1326` 注释明确）；磁盘挂载点在 tooltip 内独立滚动区（`.mt-disk` max-height 160px）；modal 标题栏宽度跟随内容容器（`:has()` 三组规则，`style.css:373-375`）。
- 移动端两级断点（≤640px 双列卡片/隐藏文件时间列/弹窗全屏，≤420px 单列），概览条网格自适应。

**可改进（Low）**：

- **L15**：文件上传/下载仅有文本百分比（`file-msg`），无进度条/取消下载按钮（上传有取消，下载没有）。

## 3. 用户体验

**做得好的**：

- **空闲观看保护**（`app.js:458-501`）：10min 无操作 → 确认弹窗 → 60s 无响应自动暂停实时刷新（agent 回慢采省额度），任何操作恢复——类似视频网站"继续观看？"，与额度目标闭环。
- **后台标签页关 WS**（`503-511`）、终端 **8s 无数据自愈重建**（`599-608`）、终端断线指数重连（1s/2s/3s，上限 3 次）+ 权限失效（1008）明确提示。
- **可访问性系统化**（`1493-1530`）：MutationObserver 统一注入 `role="dialog"`/`aria-modal`、打开自动聚焦首个可聚焦元素、关闭恢复触发焦点、Esc 走既有清理路径（终端 ws/resize 正确释放）。
- 文件过滤 Everything 风格（无通配符自动包子串匹配，`670-674`）、过滤在 agent 端完成避免截断遗漏；通用 dialog 替代系统 alert/confirm；表单 Enter 提交、打开弹窗自动聚焦。

**问题**：

- **M2 文件 WS 静默失效**：`ws.onclose` 仅置 `fileWs=null`（`728`），之后 `fileSend` 静默丢弃（`745-747`）——断线后用户点击目录/刷新无任何反馈也无重连（终端有重连机制，文件没有，行为不一致）。
- **M3 推送重连耗尽后无恢复入口**：`pushRetries < 5` 用尽后仅 toast"请刷新页面"（`440-445`），无自动恢复或重试按钮——长时间挂后台的页面需手动刷新。
- **L4 空闲确认弹窗 timer 泄漏**：弹窗显示期间任何 mousemove/keydown → `resetIdle()` 清掉 `idlePromptTimer`（`467-472`）→ 弹窗不再 60s 自动暂停，永久滞留需手动点掉。修：弹窗显示期间不重置 prompt timer，或 resetIdle 时同步关闭该弹窗。
- **L6 下载无并发防护**：连续点击两个下载，第二个覆盖 `fileDownload`，第一个的 `read_result` 报"下载状态异常"（`771-775`）。修：进行中禁用或排队。
- **L12 登录按钮无 loading 态**：响应慢时重复点击重复请求（`doLogin` 无防护）。
- **L13 PAT 无 exec 权限时菜单仍显示终端/文件**，点击后服务端 403 才 toast——可按权限预隐藏。
- **L14 指标 tooltip 为静态快照**：打开后不随推送更新（数据时点模糊），可接受但建议标注或自动关闭。

## 4. 性能

**做得好的**：

- **增量 DOM 更新**（`updateServerCards` 305-357）：推送到达只更新徽章/指标/探活块，不重建卡片——防 hover 抖动与菜单销毁；结构变化才全量重建。每秒老化只触碰徽章与概览条（`updateAging`）。
- **长区间降采样**（`downsample` 870-885，目标 240 点）；Chart 实例先 destroy 再重建（防内存泄漏）；Blob 直接引用分块数组避免 500MB 二次拷贝（`791-798`）；上传 stop-and-wait 队列有界（1 块在途）。
- 事件委托（卡片菜单/文件列表/tooltip 均委托，卡片重建不丢绑定）；geo 查询有缓存 + 私网过滤 + 5s 超时 + 主备切换。

**问题**：

- **L7 geo 查询串行**：`lookupGeo` 逐个 `await`（`232-240`），15 台机器最坏 15×10s（主备各 5s）= 75s 才全部显示归属地。修：`Promise.allSettled` 并行（各有独立超时，顺序无关）。
- **L9 chart.js 在 head 同步加载**（`index.html:12`）：205KB 阻塞首屏解析。修：加 `defer` 或移到 body 末尾（图表仅在弹窗中使用，首屏不需要）。
- **L11 自定义指标图 O(n²) 查找**：`app.js:1016` 在 `tsArr.map` 内 `find`——监控图已用 `Map`（`934`），此处未对齐。1,000 点 ×20 指标时约 2 万次比较（可感知卡顿边缘）。
- **提示**：`updateAging` 每秒 `querySelectorAll('.card')` + `serversCache.find` 为 O(n²)，S≤100 无感，更大规模可用 Map 索引。

## 5. 安全

**逐项核验通过（无漏洞）**：

1. **CSP**（`index.html:8`）：`script-src 'self'`（无 inline/unsafe-eval）→ XSS 脚本执行面极小；`frame-ancestors 'none'` 防点击劫持；`connect-src` 白名单仅 self/ws/wss/两个 HTTPS geo 服务。
2. **输出编码全覆盖**：所有服务端数据进入 `innerHTML` 前均过 `escapeHtml`——逐一核对 `cardHtml`（name/group/info）、`probesBlockHtml`、`metricTipHtml`（info/disk 挂载点）、`renderFileList`（文件名/路径）、`loadTokens`、`loadAuditLogs`、`loadUsage`；`confirmDialog`/toast/title 均走 `textContent`。
3. **`data-metric` 属性内嵌 JSON**（`152`）：JSON 经 escapeHtml 后嵌入，读取时浏览器自动反转义再 `JSON.parse`——闭环正确。
4. **凭据处理**：token 仅 localStorage + Authorization header（无 cookie → CSRF 天然免疫）；token 不进 URL（防日志/历史泄露）；PAT/agent_key 明文展示均"仅显示一次"对话框。
5. **第三方隐私**：geo 查询默认关闭、私网/保留地址正则过滤、仅 HTTPS、开关处有明确文案（`index.html:146-148`）。
6. **终端数据**：`term.write` 写入服务端内容是终端预期行为（xterm 非 HTML 解析，无注入面）。
7. vendor 本地化 + CSP `script-src 'self'` 组合，供应链风险可控。

**已知接受项**（此前 review 已记录）：token 存 localStorage（XSS 时可窃取，但 CSP 下注入面已极小）；静态 HTML 的 CSP 靠 meta 而非 HTTP 头（`frame-ancestors` 在 meta 中无效——依赖服务端响应头补充，若无则点击劫持防护仅靠 frame-ancestors 缺失时的默认行为，**建议确认 Worker 静态资产响应是否带 frame-ancestors 头**——若无，`X-Frame-Options: DENY` 或响应头 CSP 是更可靠的补充）。

## 6. 逻辑

**验证为正确的关键点**（防误改）：

- 推送生命周期：`onclose` 的 `pushWs !== ws` 检查防旧连接干扰（`431`）；1008 清登录态防重连死循环；后台/恢复与空闲暂停/恢复状态机无冲突。
- 终端：`auth` 先于 `fit.fit()` 发送（`594-598` 注释解释 resize 抢先问题）；`noDataTimer` 与 `rebuilding` 标志防重复重建；关闭路径 removeEventListener('resize') 防泄漏。
- 上传：stop-and-wait + `upload_id` 唯一 + 按真实 `written` 累计 + `commit` 原子写闭环；取消发 abort 清 agent 临时文件。
- 下载：`got=0` 中止防无限循环（文件缩短场景）；`parts` 数组 Blob 直引。
- 在线老化：20s = 服务端快宽限 15s + 5s 余量（`265-274`），无指标服务器保留服务端判定不覆盖。

**问题**：

- **M1 取消上传的 NPE 窗口**（`818-836, 840-846`）：`reader.onload` 闭包引用全局 `fileUpload`，`cancelUpload()` 置 null 后，FileReader 异步读完成触发 onload → `fileUpload.sent` 抛 **TypeError**（上传中断且无错误提示）。修：onload 内首行判空 `if (!fileUpload) return;`，或闭包捕获局部状态对象。
- **L5 监控 range 快速切换竞态**（`887-904`）：无请求序号/AbortController——慢的旧 range 响应后到会覆盖新 range 的图表（短暂错显后自愈）。修：请求序号比对丢弃过期响应。
- **L8 目录点击不带过滤规则**（`1486-1488`）：点击目录直接 `fileSend({type:'list'})`，未走 `reloadFileList()`——当前过滤词下进入子目录后列表不再过滤，与「刷新」按钮行为不一致。修：统一调 `reloadFileList()`。
- **L10 文件 msg 残留**：`list_result` 仅在 `truncated` 时写提示（`723`），从截断目录切到正常目录后"仅显示前 1000 项"提示不消失。修：非截断时清空。
